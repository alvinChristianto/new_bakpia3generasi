
# 🥮 Bakpia Master: The Vibe-Coded Storefront

Welcome to **Bakpia Master**, a premium e-commerce transaction system for Indonesia's favorite traditional pastry. This project is a testament to the power of **"Vibe Coding"**—where big ideas meet rapid AI execution.

Built with **Next.js 15**, **Laravel**, and **MySQL**, this system moves from a "craving" to a "completed transaction" in record time.

## 🛠️ Tech Stack

* **Frontend:** Next.js 15 (App Router), Tailwind CSS, Shadcn UI, Framer Motion.
* **Backend:** Laravel 11+ (REST API).
* **Database:** MySQL.
* **State Management:** LocalStorage + Zustand (for that lightning-fast cart).
* **Payment:** Midtrans/Xendit Integration.

## 📦 Getting Started: Next.js Installation

To get the frontend up and running, follow these steps:

### 1. Initialize the Project

Open your terminal and run:

```bash
npx create-next-app@latest bakpia-frontend

```

**Recommended settings during setup:**

* **TypeScript:** Yes
* **ESLint:** Yes
* **Tailwind CSS:** Yes
* **src/ directory:** Yes
* **App Router:** Yes
* **Import alias (@/*):** Yes

### 2. Enter the Directory

```bash
cd bakpia-frontend

```

### 3. Add Shadcn UI (The v0 Foundation)

Since v0 uses Shadcn components, initialize it in your project:

```bash
npx shadcn-ui@latest init

```

### 4. Paste your v0 Components

Copy the code generated by **v0.dev** (like the `CartSidebar` or `ProductGrid`) into your `/components` folder and watch the magic happen.

### 5. Run the Development Server

```bash
npm run dev

```

Navigate to `http://localhost:3000` to see your Bakpia store in action!

## ✨ Key Features Implemented

* ✅ **Dynamic Product Grid:** Fetching Bakpia types from a Laravel-powered MySQL DB.
* ✅ **Slide-out Cart:** A right-sidebar cart that persists data to `localStorage`.
* ✅ **User Profiles:** Granular address management (Rumah, Kantor) for delivery.
* ✅ **Seamless Checkout:** Integration-ready for Indonesian Payment Gateways.
* ✅ **Transaction History:** A clean list of past orders with real-time status updates.
